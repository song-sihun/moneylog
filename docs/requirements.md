# 머니로그(MoneyLog) 요구사항 정의서

- 작성자: 송시훈
- 작성일: 2026-07-22
- 프로젝트 기간: 5일

## 1. 프로젝트 개요

- 한 줄 소개: 개인이 수입/지출을 기록하고 카테고리별·월별 통계를 보는 가계부 웹 서비스
- 대상 사용자: 로그인한 개인 사용자(내 데이터는 나만 접근)
- 목표: (예) 부트캠프 전 과정 복습 + EC2 실배포까지 완주

## 2. 유저 스토리

| #    | 유저 스토리 (~로서 나는 ~하고 싶다, 왜냐하면 ~)                                                          |
| ---- | -------------------------------------------------------------------------------------------------------- |
| US-1 | 사용자로서 내 계정을 회원가입, 로그인을 하고 싶다. 다른 유저가 내 정보를 알게 하고 싶지 않음             |
| US-2 | 사용자로서 나의 수입/지출 내역을 등록,수정,조회,삭제 하고싶다. 어떤 내용으로 돈이 흐르는지 파악하기 위해 |
| US-3 | 사용자로서 수입/지출을 카테고리별 필터링 하고싶다. 어디에 사용되는지 알고싶음                            |
| US-4 | 사용자로서 수입/지출을 오름차순 또는 내림차순 정렬로 보고싶다. 역순으로도 조회하고 싶음                  |

## 3. 기능 요구사항 (MoSCoW)

| ID   | 기능             | 설명                                                         | 우선순위(Must/Should/Could) |
| ---- | ---------------- | ------------------------------------------------------------ | :-------------------------: |
| F-01 | 회원가입/로그인  | JWT 발급, BCrypt                                             |            must             |
| F-02 | 거래내역 CRUD    | 수입/지출 등록·조회·수정·삭제                                |            must             |
| F-03 | 목록 필터·페이징 | yearMonth/type/categoryId + page/size                        |           should            |
| F-04 | 월별 통계        | 총수입·지출·잔액, 카테고리별 지출                            |            could            |
| F-05 | 인가             | 본인 데이터만                                                |            must             |
| F-06 | 검증·예외        | 금액>0, 날짜 필수, {success:false, code, message, data:null} |            must             |
| F-07 | 프론트 4종       | 로그인/목록/등록/통계                                        |            must             |
| F-08 | Swagger          | API 문서화                                                   |            could            |
| F-09 | 배포             | Docker+GitHub Actions+EC2                                    |            must             |

## 5. 범위(Scope)

| 구분                        | 내용                                 |
| --------------------------- | ------------------------------------ |
| 기본 과제 (In Scope)        | 계정 회원가입,로그인 / 수입지출 CRUD |
| 도전 과제 (Stretch)         | Swagger API 문서화                   |
| 이번엔 안 함 (Out of Scope) | 수입지출 통계 시각화, OAuth2         |
