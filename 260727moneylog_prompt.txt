현재 경로에 moneylog-front라는 폴더를 만들어주세요.
그 안에 Spring Boot로 구현된 가계부(MoneyLog) 백엔드 API와 연동할 React(Vite + Tailwind CSS + Axios) 프론트엔드 웹 애플리케이션을 만들어주세요.

[프로젝트 핵심 요구사항]
1. SPA(Single Page Application) 구조로 작성하고, React Router를 활용해주세요.
2. HTTP 클라이언트는 Axios를 사용하며, JWT 인증 처리용 공통인터셉터(Axios Interceptor)를 구현해주세요.
3. 디자인은 Tailwind CSS를 활용해 깔끔하고 모던한 가계부 UI로 만들어주세요.

---

[백엔드 API 엔드포인트 및 DTO 명세]

1. 회원가입
- POST /auth/signup
- Request Body: { "email": "string", "password": "string", "nickname": "string" }
- Response: 200 OK

2. 로그인
- POST /auth/login
- Request Body: { "email": "string", "password": "string" }
- Response Body: { "accessToken": "string", "tokenType": "Bearer", "email": "string", "nickname": "string" }
* 처리 조건: 로그인 성공 시 accessToken을 localStorage에 저장하고 메인 가계부 페이지로 이동.

3. 거래 내역 목록 조회 (인증 필요)
- GET /moneylog?startDate=YYYY-MM-DD&endDate=YYYY-MM-DD&page=0&size=10&sort=date,desc
- Header: Authorization: Bearer {token}
- Response Body: Page<TransLogResponseDto> (Spring Data Page 객체 구조)
  - content: [ { "id": number, "type": "INCOME"|"EXPENSE", "amount": number, "category": string, "description": string, "date": "YYYY-MM-DD" } ]
  - totalPages, totalElements, number 등 페이징 정보 포함

4. 거래 내역 등록 (인증 필요)
- POST /moneylog
- Header: Authorization: Bearer {token}
- Request Body: { "amount": number, "type": "INCOME"|"EXPENSE", "category": string, "description": string, "date": "YYYY-MM-DD" }

5. 거래 내역 수정 (인증 필요)
- PUT /moneylog/{id}
- Header: Authorization: Bearer {token}
- Request Body: { "id": number, "amount": number, "type": "INCOME"|"EXPENSE", "category": string, "description": string, "date": "YYYY-MM-DD" }

6. 거래 내역 삭제 (인증 필요)
- DELETE /moneylog/{id}
- Header: Authorization: Bearer {token}
- Response: 204 No Content

[화면 구성 및 요구 기능]
1. 로그인 / 회원가입 페이지 (탭 또는 페이지 분리)
2. 메인 가계부 페이지:
   - 상단: 달력/날짜 범위 선택 (기본값: 이번 달 1일 ~ 오늘)
   - 중단: 수입/지출 내역 등록 폼 (모달 또는 상단 입력창)
   - 하단: 거래 내역 리스트 (수입은 파란색/지출은 빨간색 표시, 수정/삭제 버튼 제공)
   - 하단: 페이징 버튼 (이전/다음)

우선 전체 구조를 다룰 수 있도록 `api/axios.js` (인터셉터 포함), `App.jsx`, 그리고 핵심 메인 가계부 컴포넌트 코드를 작성해 주세요.
